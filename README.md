## 🌟 Why MultiTool?

Tired of visiting sketchy websites that upload your documents to unknown servers? MultiTool solves this with a radical approach: **everything runs locally in your browser**.

> 🔒 **Privacy-First Philosophy:** Your files never leave your device. Not even for a millisecond. Process sensitive PDFs, encrypt confidential data, and handle private images with total confidence.

<br>

### ✨ Core Features

| Feature | Description |
|---------|-------------|
| 🖥️ **100% Client-Side** | Every tool runs entirely in your browser using modern Web APIs |
| 🔐 **Zero Server Processing** | Absolute privacy — no uploads, no tracking, no data collection |
| ⚡ **Lightning Fast** | Instant tool switching with lazy-loaded components and code splitting |
| 📴 **Offline-Capable** | Works without an internet connection after initial load |
| 🌙 **Dark / Light / OLED Mode** | Three theme options with persistent preferences |
| 📱 **Fully Responsive** | Optimized for mobile, tablet, and desktop with collapsible sidebar |
| 🔗 **Hash-Based Routing** | Shareable URLs, browser history support, and page refresh resilience |
| 🎨 **62 Production Tools** | From PDF editors to AES encrypters — all in one place |
| ♿ **Accessible** | ARIA labels, keyboard navigation, and semantic HTML throughout |
| 🧩 **Modular Architecture** | Add new tools in minutes with our clean component system |

## 🚀 Quick Start

Getting MultiTool running locally is incredibly simple. No complex setup, no backend servers, no databases.

### Prerequisites

- **Node.js** 18+ (LTS recommended)
- **npm** or **yarn** or **pnpm**

### Installation

```bash
# Clone the repository
git clone https://github.com/Shishir-ip/Multi-Tool-Utility-Web-App.git
cd multitool

# Install dependencies (only CDN wrappers and type definitions)
npm install

# Start the development server
npm run dev
```

The app will be available at `http://localhost:5173` (or the port shown in your terminal).

### Production Build

```bash
# Build for production
npm run build

# Preview the production build
npm run preview
```

The optimized output lands in the `dist/` folder — ready to deploy to **Vercel**, **Netlify**, **GitHub Pages**, or any static host.

> 💡 **Pro Tip:** Since everything is client-side, you can even host MultiTool on GitHub Pages for free with zero server costs!

## 🧩 How to Add a New Tool (Contributor Guide)

We've designed MultiTool to be **extremely contributor-friendly**. Adding a new tool takes about 10 minutes and touches only 3 files.

### Step 1: Register the Tool

Open `src/types.ts` and add a new entry to the `TOOLS` array:

```typescript
{
  id: 'my-awesome-tool',           // Unique ID (used in URL hash)
  name: 'My Awesome Tool',         // Display name
  category: 'Developer & Coding',  // Must match an existing category
  description: 'Does something amazing',
  icon: 'fa-rocket',               // FontAwesome icon class
  keywords: ['awesome', 'tool']    // For search indexing
}
```

### Step 2: Create the Component

Create a new file in `src/tools/` — either a standalone file or add to an existing category module:

```tsx
// src/tools/MyNewTools.tsx
import React, { useState } from 'react';
import { ToolHeader, Button } from '../components/Shared';

export const MyAwesomeTool: React.FC = () => {
  const [value, setValue] = useState('');

  return (
    <div className="tool-container">
      <ToolHeader
        icon="fa-rocket"
        title="My Awesome Tool"
        description="Does something amazing"
        color="#3b82f6"
      />
      <input
        value={value}
        onChange={e => setValue(e.target.value)}
        className="input-field"
        placeholder="Type something..."
      />
      <Button onClick={() => alert(value)} icon="fa-rocket">
        Launch
      </Button>
    </div>
  );
};
```

### Step 3: Register the Route

Open `src/App.tsx` and add a lazy-loaded entry to the `ToolModules` object:

```typescript
const ToolModules: Record<string, React.LazyExoticComponent<React.FC>> = {
  // ... existing tools
  'my-awesome-tool': lazy(() =>
    import('./tools/MyNewTools').then(m => ({ default: m.MyAwesomeTool }))
  ),
};
```

### ✅ That's It!

Your tool will automatically:
- ✅ Appear in the dashboard under its category
- ✅ Be indexed by the search bar (via `keywords`)
- ✅ Have its own shareable URL (`#/my-awesome-tool`)
- ✅ Support browser back/forward navigation
- ✅ Be lazy-loaded for optimal performance

> 🎉 **First-time contributors welcome!** Check out issues labeled [`good first issue`](https://github.com/Shishir-ip/Multi-Tool-Utility-Web-App/issues?q=is%3Aissue+label%3A%22good+first+issue%22) to get started.

## 🛠️ Tech Stack & APIs

### Core Stack

| Technology | Purpose |
|------------|---------|
| **React 18** | Component-based UI with hooks |
| **TypeScript** | Type-safe development |
| **Vite** | Lightning-fast build tooling |
| **Tailwind CSS 4** | Utility-first responsive styling |
| **React Router (Hash)** | Client-side navigation with URL persistence |

### Native Web APIs Used

| API | Usage |
|-----|-------|
| 🔐 **Web Crypto API** | AES-256-GCM encryption, PBKDF2 key derivation |
| 🎵 **Web Audio API** | Audio trimming, waveform visualization, mic volume meter |
| 🎨 **Canvas API** | Image processing, cropping, steganography, paper generation |
| 📹 **MediaDevices API** | Camera and microphone access for inspector tool |
| 📂 **FileReader API** | Client-side file reading without uploads |
| 📦 **File API** | Drag-and-drop, batch processing, ZIP creation |
| 🖥️ **Fullscreen API** | Immersive mode for time & focus tools |
| 💾 **LocalStorage API** | Theme and sidebar preference persistence |

### CDN Libraries

| Library | Version | Purpose |
|---------|---------|---------|
| **jsPDF** | 2.5.1 | PDF generation from images and canvas |
| **pdf-lib** | 1.17.1 | PDF manipulation (merge, extract, reorder) |
| **pdf.js** | 3.11.174 | PDF rendering to canvas |
| **JSZip** | Latest | Batch ZIP file creation |
| **QRCode.js** | 1.0.0 | QR code generation |
| **FontAwesome** | 6.4.0 | Icon system across all tools |
